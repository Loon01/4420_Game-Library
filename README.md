# 4420 Advanced Database

Game Library

Our project was to create a large database that held thousands of games with Users Owning or Wanting
games. We wanted to use waht we learned in our adv. database class and use an index to help improve 
search time with a large database.

We used an API called IGDB to help get data for games (https://www.igdb.com/api)
We used our school server to create our database and to do tests.
